# 特征说明

一人一行，只用 `subject_table.csv` 里保留的那次筛查。被 `Additional ID` 放下的 2014 年录音不读取。

模型使用的列在 `feature_columns.txt`。`child_id`、`split`、`campaign`、`murmur`、`supervised` 只用于划分和评价，不进入模型。杂音描述、`Outcome` 和妊娠不在表里。

人口学以儿童为年龄参照、女性为性别参照。空白年龄单独成一列。身高、体重保留缺失，并带有缺失指示。中位数填补留到逻辑回归，只在训练集上拟合。

四个标准位置各有一组列。没有录音时，该位置的缺失标记为 1，其余为空白，不用其他人的均值填。同一位置多段时保留较长的一段，并把重复标记设为 1。`n_phc` 只计其他位置的段数，没有频谱列。

时间摘要来自公开分割里时长大于 0 的状态：1 是 S1，2 是收缩期，3 是 S2，4 是舒张期。状态 0 和长度为 0 的标记不使用。`rr` 是相邻 S1 起点间隔的平均值。

频谱在这些状态对应的采样上计算，按片段长度加权。三段能量分别是 25–120 Hz、120–400 Hz、400–800 Hz，分母是该片段的总功率。`50782_MV_1.wav` 没有可用分割，时间摘要留空，频谱改用整段录音。

```bash
python3 scripts/03_extract_features.py
```
