# 数据质量校验

校验对象是 PhysioNet CirCor 1.0.3 公开训练集，以及按 `proposal/项目执行标准.md` 生成的 872 名儿童。脚本只读原始文件。

## 结论

文件、标签和划分与锁定规则一致，没有阻塞项。可以进入特征提取。分割覆盖不完整，时间特征只使用状态 1–4，这个限制保持不变。

## 完整性

- 受试者 `.txt` 942 个，与 `training_data.csv` 的患者编号一致。人口学和标签字段不一致 0 条，听诊位置列表不一致 0 条。
- 录音 `.wav` / `.hea` / `.tsv` 各 3163 个。txt 点名的文件缺失 0 个，目录里没有被 txt 点名的 wav 0 个。
- 全部录音都是 4000 Hz、单声道、16-bit，文件长度等于 44 字节头加采样点。格式异常 0 段。
- 全部录音时长合计 20.09 小时，最短 5.15 秒，中位 21.46 秒，最长 64.51 秒。

## 分析队列

- 872 名儿童，每人一行。2014 与 2015 都参加的 70 人保留 2015 年这次。被放下的编号没有再出现在模型行里。
- 标签：Absent 652，Present 158，Unknown 62。已标注儿童里 Present 占 19.5%。
- 70 对关联记录里，两次杂音标签不一致 15 对。模型使用 2015 年那次自己的标签。
- 划分种子 6018。训练 610、验证 131、测试 131，三类人数与 `split_counts.csv` 一致。

## 缺失、不平衡和泄漏

- 年龄缺失 74 (8.5%)。身高缺失 114 (13.1%)，体重缺失 105 (12.0%)。没有小于等于 0 的身高或体重。
- 妊娠为真 70 人，其中年龄缺失 70 人。妊娠不进入特征。
- 四个标准位置至少缺一个的儿童 308 (35.3%)。主动脉缺 138 (15.8%)，肺动脉缺 157 (18.0%)，三尖瓣缺 187 (21.4%)，二尖瓣缺 83 (9.5%)。
- 保留这次筛查里，同一位置有多段录音的位置组 16 个。特征将使用其中较长的一段，得到 2925 段录音，合计 18.27 小时。`Phc` 在这些选中录音里有 2 段，不进入四个位置的特征。
- Absent 和 Unknown 的杂音描述列有内容的儿童为 0。Present 的 158 人全部有杂音位置。这些描述列不进入特征。

## 分割覆盖

- 3,163 段录音都有分割文件。16 段在末尾有长度为 0 的标记，校验时略过。非法正时长标签 0 段。
- 没有可用 S1 和 S2 的录音是 1 段：50782_MV_1.wav。
- 状态 1–4 占录音时长的比例，全部录音中位数 51.7%，均值 54.5%。将进入特征的 2925 段里，中位数 51.8%，均值 54.6%，低于一半的有 1404 段。
- 进入特征的录音里，没有 S1/S2 的是 `50782_MV_1.wav`。这些位置仍保留录音和缺失标记，时间摘要留空。
- 状态 0 是未归入心动周期的区段。时间摘要只在状态 1–4 上计算。
